# Rupantara Explorer 3D — Update Video Budaya

Versi ini mempertahankan fitur utama dari codingan Rupantara yang diberikan dan menambahkan video interaktif pada tiga kartu Kebudayaan & Alam Nusantara.

Klik kartu Tari Topeng Betawi, Kepulauan Raja Ampat, atau Bunga Anggrek Bulan untuk membuka dan memutar video langsung di halaman.

Tidak ada link YouTube dan tidak ada pengalihan ke halaman localhost khusus video. Video disimpan sebagai MP4 lokal dengan path relatif agar dapat ikut di-push ke GitHub/GitHub Pages.


## Update integrasi Rp100.000 + Sinar UV
- Aset depan/belakang Rp100.000 dari pengguna dipakai sebagai gambar utama.
- Mode **Sinar UV** memakai comparison slider dari versi UV terbaru: geser garis kiri/kanan, tombol tukar sisi, dan modal khusus.
- Aset lokal UV: `assets/uvdpn1.png`, `assets/uvdpn2.png`, `assets/uvbk1.png`, `assets/uvbk2.png`.
- Salinan dengan penamaan pengguna: `assets/depan.spesimen.jpg` dan `assets/belakang.spesimen.jpg`.
- Tampilan UV adalah simulasi edukatif lokal; tidak membutuhkan URL gambar eksternal.


### Update UV detail
Semua tampilan uang menggunakan aset spesimen Rp100.000 yang diberikan. Layer UV memakai referensi UV yang diberikan, dengan rasio 151:65 agar seluruh detail uang tetap terlihat saat slider digeser.
